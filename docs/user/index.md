# Welcome to Pitchblend

Pitchblend is a desktop experience powered by Geist, an open-source engine for private, local AI. Geist provides the model runners, chat services, tools, and local storage that Pitchblend presents through a simpler desktop interface.

Pitchblend is currently in pre-release development. Public installers are not available yet, but developers can run Geist from source.

## What you can do today

- Run supported local models on your own hardware.
- Chat through the Geist web interface.
- Configure local and compatible online model providers.
- Store conversations in a local SQLite database by default.
- Use the developer tooling to build and test new integrations.

## Choose a guide

- **Getting Started** covers requirements and source installation.
- **Using Pitchblend** explains the major product concepts.
- **Troubleshooting** collects the first checks to make when something is not working.

Product behavior changes quickly during pre-release development. These guides describe the currently supported paths and avoid promising unreleased installers or integrations.
