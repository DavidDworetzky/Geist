# Getting Started

Pitchblend does not have public installers yet. The supported developer path is to run Geist from source using the commands in this section.

Start with **Source Installation**, then open the local application and configure a model from the Models page.

## Before you begin

- Git and Make
- The `uv` Python package manager
- Node.js for the web client
- Enough disk space for the model you choose

Apple silicon supports the local MLX path. Windows and Linux can use the managed llama.cpp path for supported GGUF models.
